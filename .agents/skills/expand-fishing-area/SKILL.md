---
name: expand-fishing-area
description: Discover Bank & Bend spots in a requested region or extend its current coverage boundary after confirming the search area with the user.
---

Ask the user which area to search and whether this is a targeted pass or a permanent expansion. Resolve only missing details: named river/corridor/counties or center, endpoints, boundary or drive-time limit, states and whether the existing footprint stays in scope. Confirm the resulting scope before searching or modifying coverage. If already explicitly supplied and approved, use it. In a noninteractive run without an agreed area, leave coverage unchanged.

Read docs/COVERAGE.md and the latest coverage inventory. Save the agreed boundary and public reference point. Search official angling, boating, agency, county and private operator inventories within that area using the find-coverage-gaps workflow. Check border cases by road to the legal parking point. Keep public map data free of personal origin coordinates. For a new jurisdiction, identify its licensing, retention, emergency-rule, stocking and health authorities before adding locations.

Record old and new boundaries separately, candidates examined and reasons for inclusion or exclusion. A targeted search need not change the permanent envelope or app filter limits. Preserve existing IDs and saved filters. Verify accessible banks, attach sources, score each new spot, reconcile overlaps, and follow docs/UPDATE-PROTOCOL.md through production verification.
